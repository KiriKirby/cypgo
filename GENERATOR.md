# PGD generator

Run from this directory:

```text
go run ./cmd/build -out cypgo.pgd
```

The release generator writes only reviewed structured source CSV files into the runtime bbolt schema described in `DATA_SCHEMA.md`. Plant resources are downloaded, inspected, and converted one resource at a time by a dedicated command or a manually reviewed CSV. The legacy normalized-text scanner remains only as comparison code and cannot contribute records to a published PGD.

FASTA extraction is strictly local to the downloaded Dr. Nelson resource being reviewed. Each resource command documents its exact headers, sheets/columns or block boundaries, comparison-record exclusions, fragments, pseudogenes, duplicate names, and ambiguous residues. No UniProt, NCBI, or other external sequence source is used. Source uncertainty remains in the audit and sequence; the generator does not repair it.
