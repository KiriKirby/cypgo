## Resource-specific interpretation

`Sheet1` is the older 95-name list. `Sheet2` is the expanded relationship table with 168 source rows, explicit CYP names in K and literal proteins in L; it updates several older names and adds many records. Therefore only Sheet2 rows 2–169 are published, preserving its duplicate/alternate rows rather than appending the superseded name list. Metadata columns remain provenance. Only terminal stops are removed; internal stops, X/x, lowercase, gaps, fragments and pseudogenes remain literal. No sequence is repaired or filled externally.
